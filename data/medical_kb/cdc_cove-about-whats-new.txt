Release Notes 2026
Features
Highlights & New Features
New visualizations
Bar and Line Race charts: A new "Racing" subtype adds Play and Replay controls to eligible Bar and Line charts. Racing Bar charts re-rank items at each time step, and Racing Line charts draw each series step by step. You can set the maximum number of bars and the playback speed.
Maps
Animate over time: State maps and world maps now have a play button so you can step through data over time.
Spanish state and territory names: When the Spanish (ES-MX) language toggle is selected, U.S. state and territory names switch to Spanish automatically.
Charts
Forecast chart legend: New legend categories and labels make it easier to tell apart estimates, partial estimates, forecasts, and the 50% and 90% confidence intervals.
Heat map refinements: Heat maps look tighter and more polished.
Sequential palettes for line charts: Line charts can now use sequential palettes. The blue palette works especially well for charts with one or two lines.
Special line effects: You have more control over where a special line effect begins and ends, including applying it to a single time increment.
Pie chart data tables: Sort arrows are hidden when the data table has only one row.
Editor and data
Remap changed columns: When you replace a data source and configured columns are missing, a new Remap Changed Columns window lets you match each one to a new column. Affected settings update automatically.
Markup variable date formatting: New Date Parse Format and Date Display Format fields let you keep dates machine-readable in the data but show them in a readable format.
Dynamic legend titles: Legend titles now support markup variables, so they can change with user selections.
Annotation resizing: You can resize text annotations to control wrapping. New Label Side options are Automatic, Left, Right, Above and Below.
Custom download file names for charts: Chart data table downloads can now use custom file names, the same way dashboard data tables do.
Clearer General panel tooltips: Tooltips for Super Title, Message (Intro Text) and Footnotes now explain more clearly what each field does.
Better Modernize button: It no longer keeps legacy accents on data bites, and it makes suggestions more selectively. That covers bar borders, Palette 2.1, axis updates and map legends, and it keeps axis tick settings you set explicitly.
New Alert component: Adds a reusable component with several alert types.
Bug fixes
When "Separate zero" is on, the zero section of a map legend now shows the suffix (for example, %).
County geocode maps no longer plot a stray dot when there's no location data.
Fixed visualizations that previewed in the editor but didn't appear on published pages.
Fixed a regression where a dashboard button stopped loading additional dashboard content.
The wave pattern fill now displays correctly on bar charts.
"Rank by value" no longer changes the shared data, so other charts using the same data aren't affected.
Box plot values are now sorted as numbers instead of text, so "2" comes before "10".
Box plot statistics (quartiles, whiskers, outliers) now use one shared calculation, so the chart and data table always match.
Small multiples tiles are now sorted as numbers, so Week 2 comes before Week 10.
Performance and behind-the-scenes improvements
The COVE bundle is about 45% smaller, so less JavaScript loads on cdc.gov pages.
Migrations and default values were refactored to make the code easier to maintain.
The state and territory lookup now comes from a CSV file, which makes adding translations easier.
The unused filtered-text package was removed. Older configurations still load it from npm.
More TypeScript cleanup, including fixing a circular dependency in filters and putting the Viewport type in one shared place.
All test packages now use Vitest v4.
Usage metrics were refined: the map load event was removed and hover behavior and titles were updated.

Zoom for World Map Enhancement for Area (Continents for Now) - Adds a zoom feature for World Maps that allows focusing on a specific continent/area. A dropdown in the Editor sets the initial zoom level when the visualization loads.
API Row Filter Field - Adds a Row Filter Field option to URL File Name filters, enabling multiple data sources from the same file. This allows a single dropdown to list options at two levels (e.g., group and items within it) where many options live inside the same file.
Support Unselected Default Value for File Name Filters - Adds an "Auto-select First Option" toggle for File Name URL filters. When deselected, filters initialize in an unselected state and target data files load only after the user makes a selection.
Add Title Option to Dashboard Filter Section - Adds an optional heading text field displayed above the dashboard filter component's intro text and controls, useful for labeling a group of dashboard filters.
Change Small Multiples Mobile Breakpoint - Changes the small multiples responsive breakpoint from medium to small, improving the mobile viewing experience.
